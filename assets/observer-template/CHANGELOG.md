# Changelog

## 1.2.1 - 2026-09-16

- 让仓库内容可通过 github-auto-publisher 的隐私门发布：把测试夹具里的合成假凭据（`Bearer secret`/`Bearer private`/`Bearer abc123`）统一换成扫描器白名单占位符 `placeholder`。
- 同步测试断言与夹具取值，避免出现永远成立的空断言。

## 1.2.0 - 2026-09-14

- 新增结构化运行时事件源，实时展示每个 Agent 的阶段、进展、文件、测试、产物、风险与 handoff。
- 新增工作流启动器：自动刷新观测台、复用或隐藏启动本地服务、健康检查并默认打开浏览器。
- 任务 CLI 自动生成 Agent 简报与交付 handoff，固定格式、路径校验、脱敏和账本写入全部下沉到脚本。
- 刷新模板时只备份被替换的代码文件，不再为版本号等非代码文件制造备份。
- 修复工作流 CLI 从模板导入模块时在被发布模板内落地 `__pycache__` 的缺陷：该残留会让下一次全量测试必然失败，并随 skill 一起分发。

## 1.1.2 - 2026-09-12

- 多任务总览按 `running`、`blocked`、`waiting`、`planned` 的稳定优先级选择主任务，避免阻塞任务被后续计划遮蔽。
- 初始化器从复制源头排除运行缓存、构建产物、备份和日志，防止污染新工作区。

## 1.1.1 - 2026-09-12

- 让 `PLANNED`、`BLOCKED` 与 `FAILED` 协调状态在主图中保留各自语义。
- 按 `-(codex|dsh|workbuddy)` 后缀合并 handoff 与原任务，避免生成幽灵任务。
- 移除可移植模板中的源机器绝对路径，并让路径测试使用通用工作区样例。

## 1.1.0 - 2026-09-12

- 将三泳道与缩进调用列表升级为用户选定的 A·DAG 四层总览：任务根、三个 Agent 分支、三个调用链摘要与观测聚合。
- 新增深色网格画布、节点详情、来源/状态筛选、缩放、适配与流动暂停控制。
- 每条可见调用边使用稳定的独立颜色，并以实体底轨、霓虹流线和边框端子共同表示关系。
- 原始事件与真实 `parent_id` 下沉到节点详情；来源/状态筛选不再破坏主图三分支，缺失证据保持显式未知。
- 边端点改用真实卡片 DOM 边界计算，并补充乱序事件、颜色稳定性、精确连卡、窄屏与 reduced-motion 测试。
- 详情补充真实 Task ID、Agent/session ID 及分离的开始/结束时间；筛选父链按完整分支判断，避免把被筛掉的父节点误报为缺失。
- 窗口变化会实时重算紧凑布局并保留键盘焦点；390px 下不再把整个画布缩成不可读的微缩图。

## 1.0.0 - 2026-09-11

- 首次发布只读多 Agent 观测台，统一 Codex、DSH、WorkBuddy 与协调状态。
- 提供 `GET /api/health`、`GET /api/snapshot`、`GET /api/events` 和本地浏览器界面。
- 提供 loopback-only Python CLI、`--once` JSON 快照模式和 PowerShell 启动器。
- 加入来源降级保留、状态证据、内容脱敏、SSE、静态路径与主要界面契约测试。
- 修复多个 `python` 命令结果被拼接执行的问题；启动器现按顺序选择首个可运行的 Python 3.11+。
- 保证 HTTP 服务器关闭失败时仍停止 observer 引擎，并加入真实 PowerShell 启动、健康检查与终止回归测试。
- 修复 Windows PowerShell 5.1 将无 BOM UTF-8 中文源码误解码后无法解析启动器的问题，并加入显式 PS5.1 生命周期回归测试。
- 修复仅心跳时间戳变化时每秒广播完整 SSE 快照的问题；现在只推送可见语义变化。
- handoff 目录不可读时将协调来源标为 `degraded`，并加强弱格式 token/password 标签脱敏。
- Agent 列表优先显示活跃会话并限制为 12 条；完成桌面、窄屏、详情展开与零 `SEVERE` 控制台错误验收。
- Codex 调用树新增 Agent 会话节点并连接 `session → turn → tool/complete`；会话限额会为被引用的父会话保留槽位，事件限额会连同祖先一起保留。
